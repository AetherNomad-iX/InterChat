# Wise Guides

## Objective

A small-business web-management practice (wiseguides.biz): demo-first sites for local operators (tree services and similar), then a monthly retainer so the owner is paid to keep them alive. Working price in conversation: **$300/month per site**. That is a working number, not a signed rate card.

## Context

The owner sells in the field and can demo a live site instead of a slide deck. GitHub already has related public properties (`willis-property-services`, `noahs-ark-lawn`) that look like this motion. InterChatProper exists so Grok/Claude/ChatGPT can keep the offer, the demo list, and the next follow-up without starting from zero each chat.
